# 自由人联合体 · C 端交互原型

面向自由职业者的机会发现、项目与任务浏览、意向提交和发布者处理原型。首页、机会大厅、任务预览和详情已默认接入共享 Java 后端的公开 API，匿名可浏览。收藏、意向、C 端发布等写操作本批未接入，真实模式中不会写入模拟数据。旧版纯前端演示可通过 `VITE_DATA_SOURCE=mock` 单独启用。

技术栈：Vue 3、TypeScript、Vite、Vue Router、Pinia、TanStack Vue Query、Element Plus。

## 手动启动与停止

建议使用 Node.js 22.12+（22.x）和 npm。当前 Vite 要求 Node.js `^20.19.0 || >=22.12.0`。

```bash
cd /Users/mainto/frontfile/freeligo
npm ci
npm run dev
```

已安装依赖且 lockfile 没有变化时，直接运行 `npm run dev`。浏览器访问 [http://127.0.0.1:5175](http://127.0.0.1:5175)。在启动终端按 **Ctrl+C** 停止服务。

开发端口固定为 5175，冲突时会退出，不会自动换端口。可用 `lsof -nP -iTCP:5175 -sTCP:LISTEN` 查看占用，确认进程归属后再处理。

## 数据模式与后端接入

默认 `VITE_DATA_SOURCE=api`，可将 [.env.example](.env.example) 复制为 `.env.local` 调整。修改 Vite 环境变量后，需要手动重启前端服务。

- 后端地址默认 `http://localhost:8080`，开发时使用 `/api` 代理；可用 `API_PROXY_TARGET` 修改代理目标。
- `VITE_API_BASE_URL` 可指定直接请求的 API 根地址，留空走同源代理。跨域直连需要后端另配 CORS。
- 后端启动时执行新增 Flyway 迁移；B 端直接使用原发布表单；保存草稿不影响正式版本，确认发布后按可见范围展示。存量正式任务在迁移时生成初始快照，无独立 C 端配置或开关。
- 分类来自后端字典；首页查询前6条并显示服务端总数，大厅按8条分页，筛选在服务端执行。
- 后端未启动或迁移尚未执行时显示请求错误，不自动切回假数据。
- 金额筛选明确计价单位；面议、非现金不显示人民币符号。无预计投入和真实视频时长时不补造。

要体验原有模拟收藏、意向、发布和选人流程，可在 `.env.local` 设置 `VITE_DATA_SOURCE=mock`，手动重启前端。以下旧版交互说明适用于 mock 模式，不代表对应真实接口已经完成。

## 模拟模式可以体验什么

| 范围 | 实现情况 |
| --- | --- |
| 首页 | 按用户参考图实现照片首屏、筛选、机会卡片、列表切换、市集与成果样例、技能导航 |
| 机会大厅与详情 | 搜索、分类和工作方式等筛选、分页、快速预览、项目与任务详情、图片放大、示例视频 |
| 登录与收藏 | 演示身份、登录后继续操作、本机账号隔离的收藏 |
| 表达意向 | 表单校验、防重复、禁止申请自己的任务、人数限制 |
| C 端发布 | 分步填写、本机草稿、预览，模拟生成一个项目及一个关联任务 |
| 发布者工作台 | 查看申请、选择承接者、检查人数上限 |
| 我的意向、报酬与履约 | 我的意向保留入口；报酬仅展示；支付、评论、飞书群、交付验收尚未实现 |

通过右上角账号菜单体验登录、收藏和发布者工作台。可选择参与者“小林”或发布者“林间工作室”，两个演示身份都能发布；后者有样例申请可处理。退出后可切换身份。成果与成长等内容目前是静态样例。

**原型说明和重置演示数据入口位于页脚。** 重置会恢复机会、收藏、意向等业务数据，但不会清除当前演示身份和发布草稿。退出登录只清除身份，不清除本机业务数据。

## 数据与项目关系

- 业务数据存于 localStorage，演示身份存于 sessionStorage；切换域名或端口会使用不同的浏览器存储。
- 真实模式列表查询后端当前正式发布且所有人可见的任务／项目，新发布默认所有人可见，历史受限快照仍由后端保护；mock 模式不调用 Java 任务 API，模拟发布也不会写入 B 端或后端。
- 当前 B 端 React 项目：`/Users/mainto/Documents/Codex/2026-09-30/https-chatgpt-com-share-6abcced2-9a98/demand-workbench`。原 `/Users/mainto/frontfile/demand-workbench` Vue 项目不作为当前维护入口。
- B/C 共用后端：`/Users/mainto/javafile/demand-workbench-backend`。
- Vite 已配置 `/api` 代理。已接入的公开查询范围见上方“数据模式与后端接入”，其余能力仍待后续实现。

本机的身份、权限和人数校验仅用于交互演示，正式系统必须由后端校验。模拟发布的一项目一任务关系不作为正式需求拆解规则。

## 项目介绍与任务展示（2026-10-25）

- “一起做”可浏览真实公开项目；任务详情可进入 `/projects/PROJECT-...` 查看所属项目及公开任务结构。

- 当前新发布默认所有人可见，个人／等级可见范围、真实 C 端登录、收藏和承接意向仍待后续接入。
