# 公开发现接入验证

日期：2026-11-11。对应本次工作区改动，未部署。

## 验证结果

- 前端 `npm run check` 通过：类型、lint、18 项测试及生产构建。仍有既有 lint 提醒和大包构建提醒。
- 后端 Java 21 下 `./mvnw -q test` 通过：106 项，105 通过、1 项既有条件浏览器测试跳过，无失败或错误。
- 后端集成测试使用 Testcontainers MySQL，覆盖审核前不可见、公开正式内容、搜索及游标分页、草稿隔离、私密与删除不可读、公开作者字段白名单、头像当前绑定和公开资格校验。
- 浏览器复用本机 5175 前端，将 API 请求转发至集成测试实际启动的后端及数据库。验证搜索、打开真实正文、搜索空态、移除分类、网络失败不回退演示内容及无页面异常。
- 1536×1024 桌面和 390×844 移动端检查；移动端无横向溢出。当前用户管理的 8070 旧进程返回的登录错误被明确显示为加载失败。

## 范围与限制

- 头像和图片签名入口的权限、关联及重定向使用测试存储实现验证；本轮没有验证线上对象存储实际图片加载及签名过期行为。
- 正文按纯文本安全展示，并显示公开图片及关联笔记；本轮不实现富文本排版。
- 不改数据库结构。新增公开查询目前依赖 JSON 字段筛选和排序，数据量增加后需结合执行计划评估索引。
- 用户管理的 8070 后端未被启动、停止或重启。用户手动重启后，新接口方可用于常规本机联调。B 端接口保持兼容，无须同步修改管理端前端。
- 发现仅展示审核通过、未删除且处于公开状态的正式笔记；写笔记与我的笔记仍仅保存本机。
