# 接口与状态管理规范

> 2026-10-25 接入更新：公开分类、首页分页筛选、大厅、任务预览和详情已接真实后端；实现见 `src/services/publicTasks.ts`，默认 api 模式，可显式切换 mock。下文关于本机数据、写操作和演示会话的描述适用于 mock 模式；收藏、意向、发布、选人仍未接入真实接口。

## 当前状态归属

| 数据 | 当前归属 |
| --- | --- |
| 机会列表、详情、申请等异步数据 | Vue Query + 业务服务 |
| 演示身份、登录后续动作 | Pinia；身份持久化到 sessionStorage |
| 筛选与可分享导航状态 | 路由 query，局部展示状态留在组件 |
| 发布草稿 | 独立 localStorage，不与查询缓存混用 |
| 模拟业务数据 | mock 服务的内存与 localStorage |

业务存储键为 `freeligo.prototype.v1`，会话键为 `freeligo.demo-user`；草稿按 `freeligo.publish-draft.<身份 ID 或 anonymous>` 隔离。演示数据升级保留部分用户操作与自建机会，不应随页面加载无条件覆盖。

页脚重置调用服务 reset 并失效查询，重置机会、收藏和意向，不清理发布草稿或当前身份。不要扩大重置含义。

## 服务与缓存

页面不得直接 fetch，通过 services/contracts 和装配入口调用服务。目前 favorite 等写操作采用手动异步状态、错误处理和查询失效；后续接入真实 API 时，优先用 useMutation 统一写操作生命周期。

favorites、hasInterest 等方法目前同步读取本机状态。**接入 HTTP 不能只替换一个实现文件**：需要将契约改为异步查询，调整调用处、查询键、加载状态、缓存更新和测试。修改契约时一起检查全部消费者。

查询键包含影响结果的筛选条件及用户身份。切换用户后不得展示前一个用户的私有缓存；成功写入后按受影响的列表、详情和申请范围失效。用户输入在编辑期间保留独立副本。

## HTTP 接入目标（尚未实现）

1. 与 Java 后端确认 DTO、公开字段、分页、错误码、认证方式和发布映射，再建立 HTTP 适配层。
2. 外部响应经过运行时校验（可使用已有 Zod），将 DTO 转为 domain；协议异常与业务失败分别处理。
3. 传递取消信号，约定超时与错误归一化，不在页面自行重复拼装 HTTP 逻辑。
4. 收藏幂等、重复申请、发布权限、所有权、人数容量必须由后端负责，并处理并发冲突。
5. 明确 Cookie / token 认证与跨域策略，不以演示身份作为真实凭证。

Vite 当前仅配置 `/api` 开发代理，默认目标 `http://localhost:8080`，通过 API_PROXY_TARGET 可调整。公开查询现已支持 VITE_API_BASE_URL；其余模拟写操作不会因此自动具备 HTTP 能力。VITE_ 变量会暴露给客户端，不能存秘密。

项目路径 `/projects/:id` 使用独立公开项目查询，项目内工作项读取当前正式快照的 project.tasks，不通过拉取全站前100个任务拼装项目。

## 新增与重构接口的约束（2026-11-09）

以下是实施要求，不代表旧适配器已全部完成：

- 通用 HTTP 处理集中在服务基础设施中，业务接口经 services 装配；页面和展示组件不解包协议、不实现轮询。当前适配器仍在 publicTasks.ts、taskInteractions.ts，重构相关能力时再收敛重复逻辑。
- 新接口遵循共享后端约定：查询 GET，变更 POST；资源编号及简单筛选通过 Query，复杂内容通过 JSON body。此约束针对 HTTP API，页面路由可以保留 `/notes/:id` 等形式。
- `{ success, msg, errorCode, errorMsg }` 在网络边界解包并以 Zod 校验，DTO 显式转换为领域模型。HTTP 失败、业务失败、非 JSON、响应结构不合法应区分；协议错误使用稳定的 `INVALID_API_RESPONSE`，不伪装为空列表或普通网络错误。
- 新增统一错误类型保留 HTTP 状态与稳定 errorCode，业务分支依赖错误码，不匹配可变中文文案；对用户展示安全提示，不透出堆栈或服务商原始错误。
- GET 使用 useQuery，写入使用 useMutation；传递 Query AbortSignal，按资源、筛选和身份构造查询键。会话退出或切换时取消并清理相应私有缓存。
- 异步审核等任务由 composable 与 Query 管理轮询，到终态停止；页面不创建重复定时器。发起任务成功不等于审核成功，不把技术任务状态当作内容已经公开。
- 空值、时间与时区按真实语义处理；没有日期、作者、成果或统计时不得补造。隐藏按钮或路由守卫不构成服务端授权。

当前后端 0.0.2 已下线旧公开任务及承接相关接口。本项目已有旧任务适配器不代表与该版本兼容；新增笔记能力必须先核对分享、分类、账号和媒体的当前契约，不能把旧任务 DTO 换名后继续使用。
