# 样式与组件规范

## 视觉基准

首页以 `docs/img/自由人联合体.png` 为确认的参考图，关注布局、间距、字号层级、色彩、图片裁切和交互状态。另一个方案图不自动替代当前基准；详情相关参考图不代表已完成实现。

内容图片可复用已授权参考素材，按钮、文字和表单必须由实际页面元素实现，不能用整张截图代替交互页面。记录素材来源，样例视频不能暗示为真实项目成果。

## 样式边界

品牌色、文字、背景、边框和尺寸优先用 CSS 变量表达；当前主要品牌色为 `#e95520`。Element Plus 的公共主题变量或 ConfigProvider 用于通用组件调整。

业务组件使用 scoped 样式或清晰的页面前缀。禁止新增全局 label、input、button 等标签规则污染其他页面，也不新增依赖组件库内部 DOM 的覆盖。先用组件公开 API、插槽和主题变量解决问题。

现有 main.css 和 reference.css 中仍有全局标签规则、内部类覆盖和追加修补，这是待整理项。首页曾受全局 label margin 影响，说明局部控件必须检查继承和计算样式；不能仅凭样式文件判断效果。

## 组件与适配

新增业务表单优先使用 Element Plus 的输入、选择、日期、弹层等能力，保持校验和键盘交互一致。首页现有原生 select 是原型实现的保留项，后续按实际需求统一，不将其描述为已经迁移。

桌面与移动端按内容调整布局，避免固定宽度导致溢出。可点击元素提供语义、可见焦点和可理解名称；不能只依赖颜色区分状态。图片提供合适替代文本并保留可预期尺寸。

小范围样式调整只验证相关页面和受影响视口；共享样式变更扩大到消费者。具体见[测试规范](测试规范.md)。
