# 我的笔记远端接入（2026-11-15）

## 范围与使用

`/?view=mine` 默认显示当前登录账号已保存的正式笔记，包含私密和待审核；`/?view=mine&source=local` 用于查看非空浏览器备份并恢复编辑，不作为常驻标签。两类数据不混排。远端支持按正文/标题搜索、总量、每页20条加载更多、全文和关联图片阅读。排序为记录发生时间与编号倒序，与既有B端时间线一致。

独立草稿与编辑副本通过“草稿”单独展示，回收站排除；私密状态不等于数据缺失。卡片显示实际公开/仅自己可见及审核状态，不通过公开发现接口读取私有正文。远端本人详情可继续编辑；写笔记提供保存草稿、私密保存、申请公开三个明确动作。有未保存内容时显示恢复入口，保留旧数据和当前账号创作恢复点。没有新增C端删除接口。

需要手动重启后端以加载新增接口，无新迁移，不需重新造数。旧后端未重启会返回接口不存在，页面显示读取失败，不回退成本机零条。本轮没有重启用户服务、改动现有开发数据或重分配笔记所有人。

## 归属与安全

新模块为consumer.notes，共用notes.OwnedNoteQuery与NoteReadRepository。不调用管理Controller，不透传管理DTO，不要求notes.use。所有权只来自AuthenticatedUser，客户端不能指定owner；数据库有界分页按owner且deleted=0/SAVED过滤，详情同样在SQL排除草稿及回收站。媒体核验本人正式记录和实际关联，再调用共用私有图片能力。

Vue Query以账号、查询类型、关键词/记录编号区分缓存；退出和换号取消并移除旧账号请求与缓存。列表错误不转换为空数据，详情错误不沿用旧正文；私人卡片不请求仅限公开内容的互动统计。

本机库只读核对结果：USER-000001/成员7418共有1005条SAVED未删除正式笔记，其中1000条展示测试批次。其他账号应只见自己的数据；不可为了展示效果改绑或复制这些记录。

## 创作接口与状态

C端consumer.notes的独立Controller/应用DTO调用共享notes.OwnedNoteEditor、NoteService、NoteMediaService和NoteReviewJobs，不透传B端DTO、不要求notes.use。新接口：

| 方法 | 路径（前缀/api/v1/c/notes） | 用途 |
| --- | --- | --- |
| GET | /editor?recordNo= | 本人正式/草稿编辑数据，优先副本，含双版本 |
| GET | /drafts?keyword=&pageSize=20&cursor= | 本人独立草稿与编辑副本分页 |
| POST | /create | clientRequestNo幂等创建，action=SAVE/DRAFT |
| POST | /save?recordNo= | expectedVersion和expectedDraftVersion联合校验 |
| POST | /review/retry?recordNo= | 重试本人当前失败审核，任务号由后端解析 |
| POST | /media/upload-token | 私有笔记图片上传授权 |
| POST | /media/complete?mediaNo= | 核验云端对象后标记可绑定 |
| GET | /media/preview?mediaNo= | 仅上传本人可预览已完成图片 |

上传完成后才能绑定；正文仅接受后端已有节点/标记白名单，阅读器逐节点渲染和转义文本，禁止v-html。标题可空，正式内容至少包含正文、配图、关联记录之一；草稿可空。私密保存不公开；PUBLIC是申请范围，实际公开以审核结果为准。正文修改会重新审核；另存编辑草稿不改变旧正式公开内容。审核异常允许显式重试，不将异常描述为违规。

编辑器使用固定3.32.0版本的TipTap Vue、StarterKit、Highlight，与B端正文JSON约定兼容，但不依赖B端组件。仅启用现有后端支持的段落、加粗、斜体、列表、链接、高亮；不新增标题层级/代码块等不支持的格式。

## 本机备份与冲突

新创作备份键freeligo.note-composer.<userNo>.<draft>，包含内容、版本与待确认的原请求，不保存Cookie/密码/上传凭证。远端状态仍归Vue Query，备份不作为远端保存成功凭证。换号同步中止编辑请求并关闭编辑器，迟到响应不清除旧账号备份或更新新账号。旧版本机库继续保留；用户明确保存才上传。

网络未知结果保留原快照并锁定再次编辑，原编号重试避免重复创建。既有笔记沿用后端乐观锁而非另建更新幂等机制；如果原保存已经成功，重试将返回409，由用户点击“保留本机副本并载入云端”核对：先将当前内容另存独立本机草稿，再载入最新主/副本版本，不自动覆盖。本机备份受浏览器存储容量/清理影响，不能代替云端草稿。

图片上传中离开编辑器会中止并忽略迟到确认；已上传但未绑定的对象仍遵循原媒体台账规则。本轮未增加云端孤立对象清理任务。

## 草稿入口简化（2026-11-16）

“我的笔记”常驻标签为“全部笔记 / 草稿”，草稿列表读取后端。浏览器备份只承担未保存内容恢复，不再作为第三个标签；有内容时显示“查看并恢复”，无内容不展示入口。旧 `source=local` 空列表链接转到草稿。

普通重开编辑器若有备份，提示“发现未保存的内容，是否恢复？”；确认前禁用编辑与提交并保护原备份。“暂不恢复”关闭编辑器且保留备份；明确从恢复入口打开则载入所选内容。恢复不自动上传，仍需用户选择保存草稿、私密保存或申请公开。备份保留原版本和待确认请求编号，延续冲突与幂等保护。

恢复提示仅在“草稿”及其恢复内容视图显示，“全部笔记”不展示。草稿标签数量来自当前账号后端草稿总数，不含浏览器保留内容，且不随搜索筛选变化。
