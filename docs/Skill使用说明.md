# Skill 使用说明

Skill 是执行辅助，不替代项目规范和用户要求。按当前会话实际可用的技能与工具选择，不能假设所有环境都已安装。

| 场景 | 可选技能与使用原则 |
| --- | --- |
| 新页面、明确重设计 | frontend-app-builder；已有用户确认参考图时以该图为基准，避免擅自换风格 |
| 已有页面的样式与交互排查 | frontend-testing-debugging；读取实际渲染状态后定位影响范围 |
| 浏览器流程自动化 | 按技能要求优先可用 Browser 能力，缺失时采用明确记录的替代方案 |
| 真实前后端联调 | verification；当前 mock 流程不能描述成真实后端链路已通过 |
| 需要新位图素材 | imagegen；仅在素材需求适合且工具可用时采用，简单 CSS 或现有 SVG 修改不需要生成图片 |

首次使用某技能时说明用途并阅读对应 SKILL.md。小范围 CSS、文案或文档调整不需要强制生成新设计稿、启动整套服务或重跑全部检查。Vue 项目不套用 Next.js / React 专用实现规则。

工具失败时记录真实原因，采取合理替代；未完成的步骤不能作为已验证结果。不要因为技能里的一般建议重复请求已有授权；涉及用户沟通或发布等行为仍遵循实际授权范围。
